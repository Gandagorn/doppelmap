About Doppelmap

Doppelmap maps face-similarity between public figures using real ArcFace face embeddings (InsightFace buffalo_l) computed over photos from the IMDB-WIKI dataset. Points are laid out with UMAP, then refined so visually-similar faces end up close together on the map. Profile photos are looked up live from Wikipedia when you click a name.

This dataset snapshot was generated on 2026-08-30.
